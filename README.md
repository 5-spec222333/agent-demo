# 前两页静态 Demo

- `01-login.html`：登录默认状态；
- `01-workspace.html`：同一页面登录成功后的工作空间选择状态；
- `02-agent-workbench.html`：Agent 工作台默认首页；
- `03-plan-confirmation.html`：方案确认页的选品与承接状态；
- `04-task-center.html`：任务中心及异常详情状态；
- `05-review.html`：审核队列、素材预览和审核操作；
- `06-material-library.html`：素材网格和素材详情状态；
- `07-launch-center.html`：投放配置和投放前检查状态；
- `08-data-analysis.html`：数据看板和 Agent 观察状态；
- `styles.css`：全部静态页面共用样式。

全部页面均已接入基础跳转与页面功能，并使用“夏季女装10条拉新视频”串联方案、生产、审核、素材、投放和数据复盘。
