# 产品背景与逻辑基线

## 产品定义

这是一个面向用户增长、电商和零售运营的 Agent 广告素材生产平台。它连接运营需求、商品与品牌资产、图片/视频模型、工程合成、审核、素材库、投放和数据分析。

## 产品成立的必要条件

1. 运营能用业务语言提出需求；
2. Agent 能识别歧义、追问并生成可确认方案；
3. 商品、频道、品牌和内容资产有明确来源；
4. 图片与视频生产可控、可修改、可重试；
5. 生成结果可审核、入库和投放；
6. 投放数据能关联回具体素材与生产参数；
7. 所有关键步骤具备状态和追溯记录。

## 底层业务变量

| 变量 | 需要回答的问题 |
| --- | --- |
| 投放目标 | 为什么生产：拉新、促活、导购、转化还是频道引流？ |
| 目标人群 | 素材面向谁？ |
| 承接对象 | 点击后进入商品页、频道页还是活动页？ |
| 选品 | 推广哪些商品，选择理由是什么？ |
| 创意表达 | 用卖点、场景、福利、测评还是对比打动用户？ |
| 素材形态 | 图片还是视频，适配哪个渠道和广告位？ |
| 资产来源 | 使用哪些商品、品牌、数字人、音乐、字幕和标签？ |
| 生成控制 | 如何控制模型、Prompt、分镜、组件和合成参数？ |
| 合规审核 | 是否满足内容、品牌、版权和广告规则？ |
| 效果反馈 | 投放是否有效，是否值得复用或继续验证？ |

## 正确业务链路

运营意图 → Agent 理解 → 歧义与缺失信息处理 → 需求确认 → 选品/承接确认 → 创意方案 → 图片方案/视频分镜 → 预览 → 批量生产 → 审核 → 入库 → 投放 → 数据回流 → 效果观察与策略沉淀。

## 技术分层

| 层 | 主要能力 |
| --- | --- |
| 交互层 | Agent 对话、配置编辑、预览确认 |
| 理解层 | 需求理解、歧义识别、缺失信息追问 |
| 资产层 | 商品库、频道库、品牌资产库、标签库、数字人库 |
| 策略层 | 选品策略、风格分配、创意结构生成 |
| 结构化配置层 | 图片方案、视频分镜、组件配置和 Schema |
| 模型层 | 文生图、文生视频、TTS、数字人等模型 |
| 合成层 | 字幕、BGM、Logo、CTA、首尾帧和视频拼接 |
| 数据层 | 任务、审核、素材库、投放数据回流和效果分析 |

## 关键风险

- Agent 退化为聊天皮肤；
- 生成结果不可控、不可复现或不可追溯；
- 知识库完全依赖人工维护，成本过高；
- 多模型视频链路失败后无法局部重试；
- 审核驳回无法定位到具体生产步骤；
- 把相关性误当因果性，过早承诺数据自动优化生成。

## 最终设计原则

运营只感知需要自己判断和确认的业务决策，系统承担底层生产复杂性。任何页面、流程或技术设计都应服务于这条原则。
