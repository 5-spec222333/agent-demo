# Agent 广告素材生产平台 Demo

这是基于 product-map/ 已确认业务关系实现的原生单页交互 Demo。贯穿案例为：

> 从夏季女装中选择合适商品，生成 10 条差异化竖屏拉新视频，并将用户承接到虚构夏装活动页。

## 打开方式

直接打开 index.html 即可离线使用。页面不依赖框架、外部字体、网络图片、真实模型或广告平台。

## 推荐演示路径

1. 在 Agent 工作台提交业务目标，完成三轮关键追问；
2. 确认结构化需求；
3. 调整 6 个主推商品顺序并确认活动页；
4. 选择创意方向，检查六镜分镜和 9:16 静态预览；
5. 创建 10 条批量任务，查看成功、处理中、部分失败、自动重试和技术降级；
6. 审核通过第一条素材；驳回第二条素材并定位到镜头 4/Logo 组件；
7. 在分镜页修改 v2，局部重制并重新送审，再通过复审；
8. 在素材库查看完整追溯，启用模拟投放；
9. 比较模拟曝光、点击和转化，补充复盘并沉淀可复用经验。

页面右上角“重置演示”或浏览器刷新都会恢复初始场景。

## 状态与版本原则

- 需求：草稿 → 解析中 → 待补充 → 待确认 → 已确认 → 已创建任务；
- 生产：待排队 → 排队中 → 生成中 → 合成中 → 质检中 → 待审核；
- 异常：部分失败 → 自动重试 → 技术处理或降级 → 返回对应镜头/组件；
- 审核：待审核 → 审核中 → 通过 / 驳回 / 待人工复核；
- 素材：待入库 → 已入库 → 待投放 → 投放中 → 已下线 → 可复用 / 已归档。

所有业务状态通过 DEMO_ENGINE.transition() 变更。驳回会保留原版本并创建新分镜/素材版本，不静默覆盖。

## Mock 边界

- 所有商品、库存、价格、活动页、品牌规则、模型版本和投放指标均为虚构演示数据；
- 视频预览由离线静态帧组成，不代表真实模型成片；
- 数据分析只陈述样本内比较与观察，不输出自动归因或因果结论；
- 图片生产在产品基线中保持独立链路，本次贯穿场景只执行视频链路。
