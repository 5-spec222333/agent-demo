# 产品整体框架图

`product-map/` 使用 HTML 展示 Agent 驱动的广告素材生产平台整体框架。

## 打开方式

直接打开 `index.html` 即可离线浏览，无外部字体、图片、框架或网络请求。

## 页面结构

- 顶部紫色箭头：运营意图到投放与数据闭环的八阶段主流程；
- 中部浅紫卡片：与各流程阶段对应的业务应用能力；
- 底部灰色卡片：资产、Agent、生产、模型、工程、数据与治理能力；
- 右侧治理栏：状态管理、版本审计和全链路追溯。

点击顶部任一流程阶段，可高亮对应的应用能力分栏。页面在 1920px 下完整展示，在 1440px 下保留清晰字号并支持横向滚动。

## 文件结构

```text
product-map/
├─ index.html
├─ styles.css
├─ app.js
└─ data/
   └─ product-map.js
```

页面结构、样式、渲染逻辑和业务文字分别维护，便于后续继续调整产品框架。
