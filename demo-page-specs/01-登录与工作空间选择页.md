# 第 1 页：登录与工作空间选择页

## 1. 页面目标

帮助用户完成三件事：

1. 注册或登录账号；
2. 在拥有多个工作空间时选择本次要进入的团队；
3. 进入 Agent 工作台。

## 2. 进入与离开规则

- 未登录用户打开产品时进入本页；
- 登录成功且只有一个可用工作空间：直接进入 Agent 工作台；
- 登录成功且有多个可用工作空间：进入本页的“选择工作空间”状态；
- 没有工作空间：展示加入或申请工作空间入口；
- 工作空间权限仍在审批：展示审批状态，不允许进入；
- 选择可用工作空间后：进入 Agent 工作台。

## 3. 页面整体布局

适配基准为 1440 × 900，页面占满浏览器视口，不展示产品后台侧边栏。

### 3.1 顶部区域

- 左上角：产品 Logo + 产品名称“营销素材 Agent”；
- 右上角：文字按钮“帮助中心”；
- 高度约 64px，左右边距 32px。

### 3.2 左侧品牌区域

- 宽度约占页面 42%；
- 使用深紫色背景，与后续 Agent 工作台的主色保持一致；
- 内容在区域内垂直居中；
- 主标题：“让运营从一句需求开始，完成素材生产与投放”；
- 补充说明：“运营负责业务判断，系统负责复杂生产”；
- 可放一张低对比度抽象背景图或 Agent 对话界面缩略图；
- 不展示“需求确认—素材生产—审核投放—数据复盘”等中部流程说明。

### 3.3 右侧操作区域

- 宽度约占页面 58%；
- 白色或浅灰背景；
- 登录卡片宽 420px，位于右侧区域水平和垂直居中；
- 工作空间选择卡片宽 560px，同样居中显示。

### 3.4 底部信息

- 页面底部居中展示：“隐私政策｜用户协议｜版本号”；
- 使用低强调度灰色文字。

## 4. 登录状态

### 4.1 登录卡片头部

- 标题：“欢迎使用营销素材 Agent”；
- 副标题：“登录后进入你的运营工作空间”；
- 页签：“账号登录”“验证码登录”；
- 默认选中“账号登录”。

### 4.2 账号登录

- 账号输入框，占位提示“手机号或邮箱”；
- 密码输入框，占位提示“请输入密码”；
- 密码框右侧提供显示/隐藏密码按钮；
- 左下为“记住登录状态”复选框；
- 右下为“忘记密码”文字链接；
- 主按钮：“登录”；
- 次级按钮：“企业账号登录”；
- 辅助入口：“收到团队邀请？通过邀请登录”；
- 卡片底部：“还没有账号？立即注册”。

### 4.3 验证码登录

- 手机号或邮箱输入框；
- 验证码输入框；
- 验证码输入框右侧为“获取验证码”按钮；
- 点击后按钮显示 60 秒倒计时；
- 主按钮：“登录”；
- 其他入口与账号登录保持一致。

## 5. 注册状态

点击“立即注册”后，在同一张卡片内切换，不打开新页面。

- 标题：“创建账号”；
- 姓名输入框；
- 手机号或邮箱输入框；
- 验证码输入框及“获取验证码”按钮；
- 密码输入框；
- 确认密码输入框；
- 勾选项：“我已阅读并同意用户协议和隐私政策”；
- 主按钮：“注册并继续”；
- 底部入口：“已有账号？返回登录”。

注册成功后：

- 有邀请关系：直接进入工作空间选择状态；
- 没有邀请关系：进入“暂无工作空间”状态。

## 6. 工作空间选择状态

登录成功且存在多个工作空间时，登录卡片替换为工作空间选择卡片。

### 6.1 卡片头部

- 标题：“选择工作空间”；
- 副标题：“选择你本次要处理运营任务的团队”；
- 右上角显示当前账号头像、姓名及“退出登录”。

### 6.2 搜索与加入入口

- 工作空间搜索框，占位提示“搜索团队或品牌”；
- 搜索框下方提供“输入邀请码加入工作空间”；
- 点击后弹出邀请码输入弹窗。

### 6.3 工作空间卡片

每个工作空间卡片展示：

- 品牌 Logo 或团队头像；
- 工作空间名称；
- 品牌名称；
- 当前用户角色，例如“运营负责人”；
- 待处理事项摘要，例如“2 个待确认方案、3 个待审核素材”；
- 最近进入时间；
- 可用空间显示“进入”按钮；
- 审批中的空间显示“权限审批中”，按钮不可用。

### 6.4 排序规则

1. 最近使用的可用工作空间；
2. 有待办事项的可用工作空间；
3. 其他可用工作空间；
4. 审批中的工作空间。

## 7. 弹窗

### 7.1 忘记密码

- 输入手机号或邮箱；
- 获取并填写验证码；
- 设置新密码；
- 成功后关闭弹窗并返回登录状态。

### 7.2 输入邀请码

- 邀请码输入框；
- “取消”和“确认加入”按钮；
- 邀请码有效时，新增对应工作空间卡片；
- 邀请码无效时，在输入框下显示具体错误。

### 7.3 申请加入工作空间

- 工作空间名称；
- 申请理由；
- “取消”和“提交申请”按钮；
- 提交成功后显示“权限审批中”。

## 8. 页面状态

### 8.1 默认状态

- 展示账号登录卡片；
- 登录按钮可点击。

### 8.2 登录中

- 登录按钮文案变为“登录中…”；
- 按钮显示加载状态；
- 输入框与其他登录入口暂时不可操作；
- Demo 模拟时长约 0.5 秒。

### 8.3 登录失败

- 卡片顶部显示错误提示，例如“账号或密码错误，请重新输入”；
- 密码框标红；
- 保留用户已输入的账号。

### 8.4 暂无工作空间

- 空状态标题：“你还没有可用的工作空间”；
- 说明：“输入团队邀请码，或申请加入已有工作空间”；
- 主按钮：“输入邀请码”；
- 次按钮：“申请加入工作空间”；
- 辅助入口：“退出登录”。

### 8.5 权限审批中

- 展示申请的工作空间名称；
- 显示“权限审批中”；
- 说明“审批通过后即可进入”；
- 提供“查看申请信息”和“退出登录”。

### 8.6 系统异常

- 卡片内显示：“暂时无法登录，请稍后重试”；
- 提供“重新登录”按钮；
- 不跳转到空白页面。

## 9. Demo 交互脚本

### 9.1 演示账号

- 账号：`demo@agent.com`；
- 密码：`123456`。

### 9.2 主演示路径

1. 用户输入演示账号和密码；
2. 点击“登录”；
3. 按钮显示“登录中…”约 0.5 秒；
4. 登录卡片切换为工作空间选择卡片；
5. 用户点击“星河女装增长团队”；
6. 页面进入 Agent 工作台；
7. Agent 工作台加载该空间的最近对话和待办摘要。

### 9.3 其他可演示路径

- 输入错误密码，展示登录失败状态；
- 点击“企业账号登录”，模拟企业身份验证成功后进入工作空间选择；
- 点击“立即注册”，展示注册表单；
- 点击“输入邀请码加入工作空间”，展示邀请码弹窗；
- 点击审批中的工作空间，仅展示审批说明，不允许进入。

## 10. 跳转关系

| 当前操作 | 结果 |
| --- | --- |
| 单工作空间账号登录成功 | 进入 Agent 工作台 |
| 多工作空间账号登录成功 | 切换到工作空间选择状态 |
| 点击可用工作空间 | 进入 Agent 工作台 |
| 点击审批中的工作空间 | 留在当前页并展示审批说明 |
| 点击“立即注册” | 切换到注册状态 |
| 点击“返回登录” | 切换到登录状态 |
| 点击“忘记密码” | 打开忘记密码弹窗 |
| 点击“输入邀请码” | 打开邀请码弹窗 |
| 点击“退出登录” | 返回默认登录状态 |

## 11. Agent 工作台接收的信息

进入 Agent 工作台时带入：

- 当前用户姓名与角色；
- 当前工作空间 ID、名称和品牌；
- 当前工作空间的待办数量；
- 当前工作空间的最近对话；
- 当前工作空间的权限范围。
