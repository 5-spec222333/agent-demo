# 第 5 页：审核与返工页

## 1. 页面目标

运营在该页面完成：

1. 查看等待审核的图片或视频；
2. 检查画面、文案、商品、品牌和承接信息；
3. 通过素材，自动进入素材库；
4. 驳回有问题的素材，并准确指定修改位置；
5. 查看返工进度和新旧版本；
6. 对返工版本进行复审。

## 2. 整体布局

采用四栏结构：

- 左侧全局导航栏：240px；
- 审核队列栏：220px；
- 中部素材预览区：自适应宽度；
- 右侧审核操作栏：360px。

在 1440px 宽度下保持四栏；空间不足时审核队列栏可以折叠。

## 3. 左侧导航栏

与其他后台页面保持一致，展示：

- 工作空间；
- 新建素材任务；
- Agent 工作台；
- 任务中心；
- 审核与返工；
- 素材库；
- 投放中心；
- 数据分析；
- 最近对话；
- 用户信息。

“审核与返工”使用紫色选中状态，并显示待审核数量“3”。

## 4. 页面顶部

### 4.1 标题区域

展示：

- 标题：“审核与返工”；
- 说明：“审核生产完成的素材，并将问题准确返回对应环节”；
- 当前任务筛选：“夏季女装 10 条拉新视频”。

### 4.2 审核统计

展示四项数据：

- 待我审核：3；
- 返工中：1；
- 待复审：1；
- 今日已通过：12。

点击统计项切换对应审核队列。

## 5. 审核队列栏

### 5.1 队列页签

展示：

- 待我审核；
- 待复审；
- 返工中；
- 我已审核。

### 5.2 搜索与筛选

提供：

- 搜索素材或任务；
- 素材类型：图片、视频；
- 风险状态；
- 提交时间；
- 任务名称。

### 5.3 素材列表项

每条素材展示：

- 素材缩略图；
- 素材名称；
- 对应商品；
- 素材版本；
- 自动检查结果；
- 等待时间；
- 当前状态。

示例：

> 视频 01｜冰丝通勤衬衫｜v1｜检查通过｜等待 12 分钟

> 视频 02｜法式收腰连衣裙｜v1｜1 项风险｜等待 10 分钟

### 5.4 队列状态颜色

- 紫色圆点：待审核；
- 橙色圆点：存在风险；
- 蓝色圆点：返工中；
- 绿色圆点：已通过；
- 红色圆点：已驳回。

## 6. 中部素材预览区

### 6.1 视频预览

展示 9:16 手机画框，支持：

- 播放和暂停；
- 拖动进度；
- 静音；
- 字幕开关；
- 倍速播放；
- 全屏；
- 循环播放。

Demo 阶段使用六张分镜图轮播模拟视频播放。

### 6.2 分镜时间轴

视频下方展示六个镜头缩略图：

- 镜头编号；
- 时间范围；
- 画面缩略图；
- 风险标记；
- 审核意见标记。

点击镜头后：

- 视频定位到对应时间；
- 右侧审核意见自动关联该镜头。

### 6.3 图片预览

图片素材展示：

- 完整画面；
- 原始尺寸；
- 放大和缩小；
- 适应画布；
- 查看文字安全区；
- 查看 Logo 安全区。

图片素材不显示视频时间轴。

### 6.4 素材基础信息

预览区顶部展示：

- 素材名称；
- 当前版本；
- 对应商品；
- 创意方向；
- 素材规格；
- 提交人；
- 提交时间。

提供：

- 查看原始方案；
- 查看生产任务；
- 返回 Agent 讨论。

## 7. 右侧自动检查结果

自动检查只作为辅助，不代替人工审核。

### 7.1 检查项

展示：

- 画面完整性；
- 商品一致性；
- 文案与活动一致性；
- 品牌 Logo 规范；
- 视频尺寸与时长；
- 字幕安全区；
- 承接页面有效性；
- 敏感或违规内容。

### 7.2 检查状态

每项状态包括：

- 通过；
- 建议检查；
- 存在风险；
- 无法判断。

### 7.3 风险示例

视频 02 显示：

> 品牌 Logo 规范：建议检查

详细说明：

> 镜头 4 中的品牌 Logo 显示时间较短，且距离画面右边缘过近。

提供按钮：

> 定位到镜头 4

点击后，中部预览自动选中镜头 4。

## 8. 人工审核区

### 8.1 审核检查清单

运营可以逐项勾选：

- 商品展示正确；
- 卖点表达准确；
- 活动价格和时间有效；
- 品牌元素符合规范；
- 字幕和口播无明显错误；
- 承接页面匹配；
- 素材可以用于投放。

清单默认不强制全部手动勾选，但存在风险项时必须处理。

### 8.2 审核备注

提供文本框：

> 添加审核备注，可选

审核通过时备注可选；审核驳回时备注必填。

### 8.3 审核按钮

底部固定展示：

- 驳回修改；
- 待人工复核；
- 审核通过。

“审核通过”使用紫色主按钮。

## 9. 审核通过

点击“审核通过”后弹出确认框：

> 确认该素材符合投放要求吗？通过后素材将自动进入素材库。

展示：

- 素材名称；
- 当前版本；
- 对应商品；
- 承接页面。

按钮：

- 取消；
- 确认通过。

确认后：

1. 审核状态变为“通过”；
2. 记录审核人和审核时间；
3. 素材自动进入素材库；
4. 审核队列自动打开下一条素材；
5. 页面顶部提示“视频 01 已通过并进入素材库”。

## 10. 驳回修改

点击“驳回修改”后，右侧切换为驳回表单。

### 10.1 问题类型

必须选择：

- 商品画面问题；
- 文案或字幕问题；
- 品牌规范问题；
- 活动信息问题；
- 分镜结构问题；
- 音频或口播问题；
- 承接页面问题；
- 其他问题。

### 10.2 问题位置

视频素材可以选择：

- 整条视频；
- 具体镜头；
- 字幕；
- 口播；
- 背景音乐；
- Logo 组件；
- 片尾行动引导。

图片素材可以选择：

- 商品主体；
- 背景；
- 主标题；
- 价格信息；
- Logo；
- 行动引导按钮。

### 10.3 修改说明

必填文本框，示例：

> 镜头 4 的 Logo 距离右边缘过近，请按照品牌安全区调整，并将展示时间延长至 2 秒。

### 10.4 返回环节

系统根据问题自动推荐返回环节：

- 文案问题 → 返回文案配置；
- 镜头问题 → 返回具体分镜；
- Logo 或字幕问题 → 返回合成组件；
- 商品错误 → 返回选品与方案；
- 承接页错误 → 返回选品与承接；
- 整体方向错误 → 返回创意方向。

用户可以查看返回环节，但默认不需要自己理解技术流程。

### 10.5 驳回确认

页面说明：

> 只返工镜头 4 的 Logo 组件，其他镜头和已完成内容将保留。

按钮：

- 取消；
- 确认驳回。

确认后：

1. 当前素材 v1 状态变为“已驳回”；
2. 保留 v1 素材和审核记录；
3. 创建返工版本 v2；
4. v2 进入返工队列；
5. 原生产任务显示“1 条返工中”；
6. Agent 工作台产生待办提醒。

## 11. 待人工复核

当运营无法判断风险时，可以点击“待人工复核”。

弹窗内选择：

- 复核人；
- 复核原因；
- 期望完成时间。

示例：

> 活动文案是否属于绝对化表达，需要品牌合规负责人确认。

提交后：

- 素材状态变为“待人工复核”；
- 不允许进入素材库；
- 指定人员收到待办；
- 当前审核意见被保留。

## 12. 返工中状态

在“返工中”页签展示：

- 原素材版本；
- 驳回原因；
- 返回环节；
- 当前返工进度；
- 预计完成时间；
- 负责人。

示例：

> 视频 02 v2｜正在调整镜头 4 Logo 组件｜合成中

用户可以：

- 查看原审核意见；
- 查看返工进度；
- 返回 Agent 讨论；
- 查看生产任务。

返工未完成时不能直接审核。

## 13. 待复审状态

返工完成后，v2 进入“待复审”。

### 13.1 新旧版本对比

中部展示双版本对比：

- 左侧：v1 原版本；
- 右侧：v2 返工版本；
- 默认定位到镜头 4；
- 同步播放；
- 只看修改位置。

### 13.2 修改摘要

右侧展示：

- 修改位置：镜头 4；
- 修改内容：调整 Logo 位置和展示时间；
- 未修改内容：其他 5 个镜头；
- 原审核意见；
- 修改完成时间。

### 13.3 复审操作

提供：

- 再次驳回；
- 复审通过。

复审通过后：

- v2 进入素材库；
- v1 保留为历史版本；
- v1 不可用于投放；
- 审核记录关联到 v1 和 v2。

## 14. 批量审核

用户可以勾选多条低风险素材进行批量审核。

批量操作包括：

- 批量通过；
- 指派审核人；
- 添加统一备注。

以下情况不允许批量通过：

- 存在自动检查风险；
- 返工后待复审；
- 商品或承接页面不一致；
- 需要人工复核。

## 15. 审核记录

点击“审核记录”打开时间线：

- 11:05 视频 02 提交审核；
- 11:08 自动检查发现 Logo 安全区风险；
- 11:12 林晓驳回视频 02 v1；
- 11:13 创建返工版本 v2；
- 11:18 镜头 4 局部返工完成；
- 11:20 视频 02 v2 提交复审；
- 11:24 林晓复审通过。

每条记录保留：

- 操作人；
- 操作时间；
- 素材版本；
- 审核结果；
- 审核意见；
- 返回环节。

## 16. 页面状态

### 16.1 无待审核素材

展示：

> 当前没有需要你审核的素材。

提供：

- 查看返工进度；
- 返回任务中心；
- 返回 Agent 工作台。

### 16.2 待审核

素材可播放并显示审核操作。

### 16.3 存在风险

自动检查结果使用橙色提示，但不自动驳回。

### 16.4 审核通过

素材进入素材库，队列自动打开下一条。

### 16.5 已驳回

素材进入返工流程，当前版本只读。

### 16.6 返工中

显示修改位置和生产进度，暂时不能审核。

### 16.7 待复审

默认展示新旧版本对比。

### 16.8 待人工复核

显示复核负责人和原因，不允许入库。

### 16.9 加载失败

展示：

> 暂时无法加载素材预览，请重新加载。

保留用户尚未提交的审核意见。

## 17. Demo 主演示路径

1. 用户从任务中心点击“前往审核”；
2. 页面自动筛选“夏季女装 10 条拉新视频”；
3. 默认打开视频 01；
4. 用户播放视频并查看检查结果；
5. 点击“审核通过”；
6. 视频 01 进入素材库；
7. 队列自动打开视频 02；
8. 系统提示镜头 4 存在 Logo 安全区风险；
9. 用户点击“定位到镜头 4”；
10. 用户选择“品牌规范问题”和“Logo 组件”；
11. 填写修改意见并确认驳回；
12. 系统创建视频 02 v2，并只返工镜头 4；
13. 用户进入“待复审”查看 v1 与 v2 对比；
14. 点击“复审通过”；
15. 视频 02 v2 进入素材库；
16. 用户点击“查看已入库素材”进入素材库。

## 18. 页面跳转关系

| 用户操作 | 跳转结果 |
| --- | --- |
| 点击素材列表项 | 在当前页打开对应素材 |
| 点击“查看原始方案” | 进入方案确认页只读状态 |
| 点击“查看生产任务” | 进入任务中心并定位对应任务 |
| 点击“返回 Agent 讨论” | 返回对应 Agent 对话 |
| 点击“定位到镜头 4” | 当前页定位到对应镜头 |
| 点击“确认驳回” | 素材进入返工中状态 |
| 点击“查看返工进度” | 进入任务中心的返工详情 |
| 点击“审核通过” | 素材自动进入素材库 |
| 点击“查看已入库素材” | 进入素材库并定位对应素材 |
