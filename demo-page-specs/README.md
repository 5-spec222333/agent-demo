# Demo 页面制作规格

本文件夹用于保存各页面已经确认的 Demo 制作信息。

## 文件规则

- 一个页面对应一个独立 Markdown 文件；
- 按用户实际使用顺序编号；
- 页面未确认前不提前写入，避免把讨论稿当成定稿；
- 每个文件需包含页面目标、布局、组件、交互、状态、跳转和 Mock 数据。
