# 第 7 页：投放中心

## 1. 页面目标

运营在投放中心完成：

1. 将审核通过的素材组成投放计划；
2. 确认投放渠道、账号、人群、时间和承接页；
3. 在投放前检查素材与业务信息；
4. 发布、暂停或结束投放；
5. 查看投放状态和基础回流数据；
6. 前往数据分析页进行素材效果比较。

投放中心只负责素材投放衔接，不做完整广告平台的复杂竞价功能。

## 2. Demo 能力边界

Demo 不连接真实广告平台，所有账号、发布状态和投放数据均为模拟数据。

页面明确标记：

> 当前为模拟投放环境，不会产生真实广告费用。

- 创建投放时，主区域切换为分步骤配置界面。

# 创建投放状态

## 9. 第一步：确认素材

从素材库批量加入投放时，自动进入该步骤。

### 9.1 已选择素材

展示两张素材卡片：

#### 视频 01

- 商品：冰丝通勤衬衫；
- 创意方向：场景种草；
- 版本：v1；
- 规格：9:16、15 秒；
- 审核状态：已通过。

#### 视频 02

- 商品：法式收腰连衣裙；
- 创意方向：场景种草；
- 版本：v2；
- 规格：9:16、15 秒；
- 审核状态：复审通过。

### 9.2 素材操作

提供：

- 预览；
- 移除；
- 更换素材；
- 继续添加素材；
- 查看审核记录。

不能选择：

- 未审核素材；
- 已驳回版本；
- 已归档素材；
- 业务信息已失效的素材。

### 9.3 底部操作

- 返回素材库；
- 下一步，配置投放。

## 10. 第二步：配置投放

### 10.1 投放名称

默认名称：

> 夏季女装新客拉新第一轮

用户可以修改。

### 10.2 投放渠道

选择：

- 短视频信息流；
- 图片信息流；
- 品牌自有频道；
- 其他模拟渠道。

选择渠道后自动检查素材规格是否匹配。

### 10.3 投放账号

下拉选择：

> 星河女装官方投放账号

展示：

- 账号状态：可用；
- 当前用户权限：可发布；
- 最近同步时间。

账号不可用时不能继续发布。

### 10.4 投放目标

选择：

- 新客拉新；
- 商品点击；
- 活动预热；
- 转化促进；
- 老客召回。

默认带入原始需求中的“新客拉新”。

### 10.5 目标人群

默认带入：

> 25—35 岁、关注通勤与轻薄穿搭的女装新客

用户可以修改为已有的人群标签，但不在 Demo 中搭建复杂人群系统。

### 10.6 投放时间

选择：

- 开始时间；
- 结束时间；
- 是否立即发布。

Demo 默认：

- 开始时间：2026 年 7 月 5 日 09:00；
- 结束时间：2026 年 7 月 12 日 23:59。

### 10.7 预算记录

填写：

- 每日预算；
- 总预算。

Demo 默认：

- 每日预算：5,000 元；
- 总预算：35,000 元。

页面提示：

> 预算仅作为模拟投放记录，不会产生真实费用。

### 10.8 承接页面

默认带入：

> 清凉一夏女装活动页

展示：

- 页面缩略图；
- 页面状态；
- 活动有效期；
- 是否包含当前商品；
- 预览承接页；
- 更换承接页。

更换承接页后必须重新检查素材文案与商品匹配关系。

## 11. 第三步：投放前检查

页面自动执行以下检查：

- 素材已经审核通过；
- 当前素材版本有效；
- 素材规格符合渠道要求；
- 商品处于可售状态；
- 商品库存正常；
- 活动时间有效；
- 素材中的价格与当前活动一致；
- 承接页面有效；
- 承接页面包含对应商品；
- 投放账号状态正常；
- 当前用户具有发布权限。

### 11.1 检查通过

显示：

> 2 条素材均已通过投放前检查，可以发布。

### 11.2 检查警告

例如：

> 法式收腰连衣裙库存偏低，请确认是否继续投放。

用户可以：

- 返回更换素材；
- 确认风险并继续。

### 11.3 检查失败

例如：

> 承接页面已经失效，暂时无法发布。

提供：

- 更换承接页；
- 返回素材库制作新版；
- 返回 Agent 处理。

检查失败时“确认发布”按钮不可用。

> 确认发布“夏季女装新客拉新第一轮”吗？

## 14. 发布过程

点击确认后：

1. 投放状态变为“发布中”；
2. 显示“正在提交素材和投放配置……”；
3. 用户可以离开页面；
4. Demo 模拟 1 秒后发布成功；
5. 状态变为“投放中”；
6. 页面显示成功提示；
7. Agent 工作台产生“投放已开始”消息。

不使用长时间虚假进度条。

## 16. 暂停投放

点击“暂停投放”后弹出：

> 暂停后将停止继续产生新的模拟曝光，历史数据会保留。

必须选择暂停原因：

- 素材需要调整；
- 商品库存不足；
- 活动信息变化；
- 数据表现需要观察；
- 临时暂停；
- 其他。

确认后：

- 状态变为“已暂停”；
- 记录操作人和原因；
- 保留全部历史数据；
- 可以重新启动。

## 17. 结束投放

点击“结束投放”后弹出：

> 结束后该投放不能直接恢复，但可以复制为新的投放计划。

必须选择结束原因：

- 活动结束；
- 商品下架；
- 预算完成；
- 素材效果不符合预期；
- 已有新素材替代；
- 其他。

结束后：

- 状态变为“已结束”；
- 停止继续产生数据；
- 素材状态变为“已下线”；
- 可以进入数据分析页完成复盘。

## 18. 发布异常

### 18.1 账号权限失效

显示：

> 投放账号授权已失效，无法继续发布。

提供：

- 重新授权；
- 更换投放账号；
- 保存为草稿。

Demo 中点击“重新授权”模拟恢复成功。

### 18.2 渠道规格不匹配

显示：

> 视频 02 的尺寸不符合当前渠道要求。

提供：

- 更换素材；
- 返回 Agent 生成适配版本。

### 18.3 渠道审核未通过

显示：

> 模拟渠道审核未通过：活动文案需要补充有效期。

提供：

- 查看具体原因；
- 返回 Agent 修改；
- 更换素材。

不删除原素材和原投放记录。

### 18.4 承接页面失效

立即暂停对应投放，并提示运营处理。

## 19. 基础回流数据

投放开始后，列表和详情展示：

- 曝光量；
- 点击量；
- 点击率；
- 转化量；
- 转化率；
- 数据更新时间。

页面提示：

> 数据为模拟回流结果，仅用于展示记录和比较能力。

不显示：

- 自动归因结论；
- 系统自主调预算；
- 系统自动替换素材；
- 未经用户确认的自动优化。

## 20. 页面状态

### 20.1 空状态

展示：

> 还没有投放计划。可以从素材库选择审核通过的素材开始投放。

按钮：

- 前往素材库；
- 新建投放。

### 20.2 待配置

配置尚未完成，可以继续编辑。

### 20.3 待发布

配置完成但尚未发布。

### 20.4 发布中

系统正在提交，不需要用户停留等待。

### 20.5 投放中

持续记录模拟投放数据。

### 20.6 已暂停

停止新增数据，可以重新启动。

### 20.7 已结束

数据冻结，可以进入复盘。

### 20.8 发布失败

显示具体原因和处理入口。

### 20.9 加载失败

展示：

> 暂时无法加载投放信息，请重新加载。

## 21. Demo 主演示路径

1. 用户从素材库选择视频 01 和视频 02 v2；
2. 点击“批量加入投放”；
3. 进入投放中心创建状态；
4. 确认两条素材；
5. 投放名称填写“夏季女装新客拉新第一轮”；
6. 选择模拟短视频信息流和星河女装账号；
7. 确认目标人群、时间、预算和承接页；
8. 系统完成投放前检查；
9. 用户点击“确认发布”；
10. 状态从“发布中”变为“投放中”；
11. 页面产生模拟曝光、点击和转化数据；
12. 用户点击“查看详细数据”；
13. 进入数据分析页并定位当前投放。

## 22. 页面跳转关系

| 用户操作 | 跳转结果 |
| --- | --- |
| 点击“新建投放” | 进入投放配置状态 |
| 点击“返回素材库” | 返回素材库并保留已选素材 |
| 点击“继续添加素材” | 进入素材库选择状态 |
| 点击“查看素材” | 进入素材库并定位对应素材 |
| 点击“查看原始任务” | 进入任务中心并定位对应任务 |

| 点击“确认发布” | 创建模拟投放并进入投放中状态 |
| 点击“查看详细数据” | 进入数据分析页并筛选当前投放 |
| 点击“复制投放” | 创建新的待配置投放计划 |
