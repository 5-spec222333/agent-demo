# 第 3 页：方案确认页

## 1. 页面目标

用户在一个页面内依次完成：

1. 查看已确认的需求；
2. 确认商品和承接页面；
3. 选择创意方向；
4. 确认视频分镜或图片方案；
5. 预览最终方案；
6. 创建生产任务。

未完成前置确认时，不能跳过并直接生产。

## 2. 整体布局

采用三栏结构：

- 左侧全局导航栏：240px；
- 中部方案确认区：自适应宽度；
- 右侧方案摘要栏：320px；
- 顶部保留当前任务名称和步骤导航。

## 3. 左侧导航栏

与 Agent 工作台保持一致，展示：

- 工作空间；
- 新建素材任务；
- Agent 工作台；
- 任务中心；
- 审核与返工；
- 素材库；
- 投放中心；
- 数据分析；
- 最近对话；
- 用户信息。

点击“Agent 工作台”返回“夏季女装 10 条拉新视频”对应对话。

## 4. 页面顶部

### 4.1 任务信息

展示：

- 返回 Agent 工作台；
- 任务名称：“夏季女装 10 条拉新视频”；
- 当前状态：“方案待确认”；
- 当前版本：“方案 v1”；
- 最近保存时间：“刚刚已保存”。

### 4.2 步骤导航

横向展示五个步骤：

1. 需求确认；
2. 选品与承接；
3. 创意方向；
4. 视频分镜；
5. 预览并创建任务。

状态分为：

- 已完成；
- 当前步骤；
- 待完成；
- 存在修改。

点击已完成步骤可以返回查看；未解锁步骤不可点击。

## 5. 第一步：需求确认

默认显示为已完成状态。

### 5.1 需求摘要

展示：

- 业务目标：新客拉新；
- 素材类型：竖屏视频；
- 数量：10 条；
- 投放渠道：短视频信息流；
- 目标人群：25—35 岁通勤女装新客；
- 视频规格：9:16、15 秒；
- 选品范围：夏季女装；
- 承接目标：夏季活动页面。

### 5.2 页面操作

提供：

- 返回 Agent 修改；
- 确认无误，下一步。

点击“返回 Agent 修改”：

- 返回对应 Agent 对话；
- Agent 询问用户要修改哪项；
- 已生成但未确认的后续方案标记为“需要重新生成”。

## 6. 第二步：选品与承接

首次进入方案确认页时，默认停留在该步骤。

### 6.1 Agent 推荐说明

顶部提示：

> Agent 根据拉新目标、目标人群、商品库存、价格和活动匹配度，推荐以下 6 个商品。

提供“查看推荐依据”，展开后展示运营可理解的信息：

- 符合夏季通勤场景；
- 价格适合新客首购；
- 当前库存充足；
- 商品正在参加夏季活动；
- 商品详情页素材完整。

不展示算法分数和内部检索过程。

### 6.2 商品卡片

每张商品卡片展示：

- 商品主图；
- 商品名称；
- 商品编号；
- 售价；
- 活动价；
- 核心卖点；
- 库存状态；
- 适合的创意方向；
- Agent 推荐理由；
- 选中复选框。

Demo 商品：

1. 冰丝通勤衬衫；
2. 高腰垂感阔腿裤；
3. 轻薄防晒针织开衫；
4. 法式收腰连衣裙；
5. 清凉亚麻西装；
6. 简约通勤半身裙。

默认全部选中。

### 6.3 商品操作

提供：

- 搜索商品；
- 按品类筛选；
- 按库存筛选；
- 更换商品；
- 移除商品；
- 调整优先级；
- 查看商品详情。

拖动卡片可以改变商品优先级。

如果移除商品，Agent 提示：

> 当前剩余 5 个商品，仍可生成 10 条差异化视频，每个商品将分配 1—3 个创意版本。

### 6.4 商品风险提示

如果商品库存不足，商品卡片显示橙色提示：

> 当前库存偏低，不建议作为批量投放主推商品。

用户可以：

- 保留商品；
- 更换商品；
- 让 Agent 重新推荐。

### 6.5 承接页面

商品区域下方展示承接页面卡片：

- 页面名称：“清凉一夏女装活动页”；
- 页面缩略图；
- 页面类型：“活动频道页”；
- 页面状态：“有效”；
- 活动时间；
- 页面包含商品数量；
- 当前选中商品是否全部包含；
- “预览页面”按钮；
- “更换承接页”按钮。

默认提示：

> 6 个推荐商品均已包含在该活动页中。

### 6.6 承接异常

如果某个商品不在活动页中，显示：

> 冰丝通勤衬衫暂未配置到该活动页，用户点击后可能无法找到对应商品。

用户必须选择：

- 将商品加入活动页；
- 更换承接页；
- 更换商品。

异常未解决前，“确认选品与承接”按钮不可点击。

### 6.7 确认操作

页面底部固定按钮：

- 返回修改需求；
- 确认选品与承接。

点击确认后：

- 商品列表和承接页生成快照；
- 状态变为“已确认”；
- 解锁“创意方向”步骤。

## 7. 第三步：创意方向

### 7.1 Agent 推荐结果

顶部说明：

> 根据拉新目标和 10 条视频的数量，建议使用 3 种创意方向，避免素材内容过于重复。

### 7.2 创意方向卡片

#### 方向一：场景种草

- 分配数量：4 条；
- 核心表达：通勤、约会、周末等真实穿搭场景；
- 适合商品：连衣裙、衬衫、半身裙；
- 开头示例：“30℃上班怎么穿得清爽又得体？”

#### 方向二：利益点直给

- 分配数量：3 条；
- 核心表达：活动价格、面料卖点和新客优惠；
- 适合商品：防晒开衫、阔腿裤、衬衫；
- 开头示例：“新客夏装限时优惠，通勤套装直接抄作业。”

#### 方向三：搭配对比

- 分配数量：3 条；
- 核心表达：普通穿法与优化穿搭的视觉对比；
- 适合商品：西装、阔腿裤、半身裙；
- 开头示例：“同一件衬衫，为什么别人穿得更显高？”

### 7.3 用户操作

每张卡片支持：

- 选择或取消；
- 修改分配数量；
- 修改核心表达；
- 查看参考样例；
- 让 Agent 重新推荐。

页面顶部实时显示：

> 已分配 10/10 条视频

如果数量不等于 10，底部确认按钮不可用。

### 7.4 风险提示

如果 10 条全部选择同一方向，Agent 提示：

> 当前 10 条视频创意结构相似，可能不利于后续比较。建议至少保留 2 种创意方向。

用户可以继续使用，但必须点击“仍按当前方案继续”。

### 7.5 确认操作

底部按钮：

- 返回选品与承接；
- 确认创意方向。

确认后解锁“视频分镜”。

## 8. 第四步：视频分镜

### 8.1 分镜顶部

展示：

- 当前创意方向；
- 对应商品；
- 视频规格：9:16、15 秒；
- 分镜版本：v1；
- “切换查看其他创意”下拉框。

### 8.2 六镜分镜结构

#### 镜头 1：开场吸引

- 时长：0—2 秒；
- 画面：高温通勤场景；
- 字幕：“30℃上班怎么穿？”；
- 作用：快速吸引目标人群。

#### 镜头 2：商品出现

- 时长：2—5 秒；
- 画面：模特展示冰丝衬衫；
- 字幕：“冰丝面料，清爽不贴身”；
- 作用：展示核心商品。

#### 镜头 3：细节卖点

- 时长：5—8 秒；
- 画面：面料和剪裁特写；
- 字幕：“轻薄透气，通勤不易皱”；
- 作用：证明商品卖点。

#### 镜头 4：搭配展示

- 时长：8—11 秒；
- 画面：衬衫搭配阔腿裤；
- 字幕：“一套解决夏日通勤”；
- 作用：提高组合购买意愿。

#### 镜头 5：活动信息

- 时长：11—13 秒；
- 画面：活动优惠和品牌信息；
- 字幕：“新客夏装限时优惠”；
- 作用：强化行动理由。

#### 镜头 6：行动引导

- 时长：13—15 秒；
- 画面：活动页缩略图和按钮；
- 字幕：“点击进入清凉一夏专区”；
- 作用：引导用户进入承接页。

### 8.3 单个镜头卡片

每个镜头展示：

- 镜头序号；
- 时长；
- 静态画面草图；
- 画面描述；
- 字幕；
- 口播；
- 使用商品；
- 品牌元素；
- “编辑镜头”按钮。

点击编辑后，在右侧打开编辑抽屉。

### 8.4 编辑镜头抽屉

运营可以修改：

- 画面表达；
- 字幕文案；
- 口播文案；
- 商品；
- 镜头时长；
- 是否使用数字人；
- 是否使用背景音乐；
- 是否展示 Logo。

不展示模型、Prompt 和合成参数。

保存修改后：

- 分镜版本从 v1 变为 v2；
- 保留 v1 历史记录；
- 页面显示“存在未确认修改”。

### 8.5 批量检查

页面顶部展示检查结果：

- 总时长：15 秒，正常；
- 商品与承接页：匹配；
- 品牌 Logo：已配置；
- 活动文案：符合当前活动；
- 必填字幕：完整；
- 风险项：0。

有风险时，点击风险项自动定位到对应镜头。

### 8.6 确认操作

底部按钮：

- 返回创意方向；
- 确认全部分镜。

确认后解锁“预览并创建任务”。

## 9. 图片素材分支

如果需求类型为图片，“视频分镜”步骤自动替换为“图片方案”。

图片方案展示：

- 画布比例；
- 商品主体位置；
- 背景场景；
- 主标题；
- 副标题；
- 价格或活动信息；
- Logo 位置；
- 行动引导按钮；
- 版式预览。

用户可以切换：

- 商品主图版式；
- 场景种草版式；
- 利益点直给版式；
- 多商品组合版式。

图片方案不展示视频镜头、时长、口播和背景音乐。

## 10. 第五步：预览并创建任务

### 10.1 预览区域

左侧展示 9:16 手机预览框。

支持：

- 播放和暂停；
- 拖动进度；
- 切换 10 条视频；
- 查看字幕；
- 静音；
- 全屏预览。

Demo 阶段使用静态分镜轮播模拟视频预览。

### 10.2 视频列表

右侧展示 10 条待生产视频：

- 视频编号；
- 商品；
- 创意方向；
- 分镜版本；
- 时长；
- 当前状态。

点击任意视频切换预览。

### 10.3 最终确认摘要

展示：

- 商品：6 个；
- 承接页：1 个；
- 创意方向：3 种；
- 视频数量：10 条；
- 视频规格：9:16、15 秒；
- 当前方案版本：v1；
- 预计输出：10 条视频素材。

### 10.4 用户确认项

创建任务前必须勾选：

- 商品和承接页已确认；
- 创意方向和数量已确认；
- 分镜、字幕和活动信息已确认；
- 当前预览可以进入批量生产。

### 10.5 底部操作

提供：

- 返回修改分镜；
- 保存方案，稍后处理；
- 确认并创建任务。

## 11. 创建任务弹窗

点击“确认并创建任务”后弹出。

展示：

- 任务名称：“夏季女装 10 条拉新视频”；
- 输出数量：10 条；
- 素材规格：9:16、15 秒；
- 负责人：林晓；
- 方案版本：v1。

用户可以修改任务名称。

按钮：

- 取消；
- 创建生产任务。

点击创建后：

1. 按钮显示“正在创建……”；
2. 成功提示：“生产任务已创建”；
3. 方案状态变为“已创建任务”；
4. 跳转任务中心；
5. 自动定位新创建的任务。

## 12. 右侧方案摘要栏

始终展示：

- 当前任务；
- 当前步骤；
- 需求摘要；
- 已选商品数量；
- 承接页面；
- 创意方向数量；
- 视频数量；
- 当前方案版本；
- 最近修改人；
- 最近保存时间。

底部提供：

- 返回 Agent 讨论；
- 查看历史版本；
- 保存当前方案。

点击“返回 Agent 讨论”时，保留当前编辑内容。

## 13. 页面状态

### 13.1 Agent 生成方案中

显示：

> Agent 正在根据已确认需求推荐商品和创意方向……

### 13.2 待用户确认

当前步骤使用橙色状态，底部显示确认按钮。

### 13.3 存在未保存修改

顶部显示：

> 当前修改尚未保存。

### 13.4 存在风险

对应步骤显示风险数量，确认按钮暂时不可用。

### 13.5 已确认

当前步骤显示绿色完成状态，自动解锁下一步。

### 13.6 方案已过期

当商品、价格、库存或活动发生变化时提示：

> 方案依赖的信息已经变化，请重新检查商品和承接页面。

### 13.7 创建任务失败

弹窗显示：

> 任务创建失败，方案内容已保存，请重新创建。

提供：

- 重新创建；
- 返回方案；
- 联系管理员。

## 14. 页面跳转关系

| 用户操作 | 跳转结果 |
| --- | --- |
| 点击“返回 Agent 工作台” | 返回对应 Agent 对话 |
| 点击“返回 Agent 修改” | 返回 Agent 工作台并发起修改 |
| 点击已完成步骤 | 切换到对应方案步骤 |
| 点击未解锁步骤 | 留在当前步骤并说明前置条件 |
| 点击“预览承接页” | 打开承接页预览弹窗 |
| 点击“查看商品详情” | 打开商品详情抽屉 |
| 点击“查看历史版本” | 打开方案版本抽屉 |
| 点击“保存方案，稍后处理” | 返回 Agent 工作台并保留待办 |
| 点击“创建生产任务” | 进入任务中心并定位新任务 |
