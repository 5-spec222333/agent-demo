# 第 8 页：数据分析页

## 1. 页面目标

运营在数据分析页完成：

1. 查看投放数据是否正常回流；
2. 查看曝光、点击和转化等基础指标；
3. 比较不同素材、商品和创意方向的表现；
4. 记录可以确认的观察结论；
5. 将有效经验保存为后续创意参考；
6. 返回 Agent 工作台创建下一轮素材。

页面只提供数据记录、比较和观察，不宣称自动归因，不自动调整预算或替换素材。

## 2. Demo 能力边界

页面顶部显示：

> 当前展示模拟投放数据，仅用于产品演示。

同时说明：

> 数据差异只能作为观察结果。多个变量同时变化时，不能直接判断具体原因。

## 19. 数据异常

### 19.1 数据尚未回流

展示：

> 投放已经开始，但暂时还没有数据返回。

提供：

- 查看投放状态；
- 稍后刷新；
- 返回 Agent 工作台。

### 19.2 数据同步延迟

展示：

> 数据最后更新时间超过 2 小时，当前结果可能不完整。

不继续生成误导性观察。

### 19.3 部分素材缺少数据

显示缺少数据的素材和原因，不将其纳入平均值计算。

### 19.4 指标定义不一致

如果不同渠道指标定义不同，禁止直接合并比较，并提示：

> 当前渠道的转化口径不同，请分别查看。

### 19.5 数据量较少

展示：

> 当前数据量较少，暂不建议形成确定结论。

## 21. 页面状态

### 21.1 无数据

投放尚未产生数据。

### 21.2 数据回流中

展示最近更新时间，不使用虚假实时动画。

### 21.3 数据正常

正常展示指标、趋势和比较。

### 21.4 数据不完整

对缺失区域进行标记，并限制 Agent 输出结论。

### 21.5 可以形成初步观察

数据具备基础比较条件，但仍标记为观察。

### 21.6 已保存复盘

复盘进入创意知识库，保留证据和适用范围。

### 21.7 加载失败

展示：

> 暂时无法加载分析数据，请重新加载。

## 22. Demo 主演示路径

1. 用户从投放中心点击“查看详细数据”；
2. 页面自动筛选“夏季女装新客拉新第一轮”；
3. 展示曝光、点击、转化和趋势；
4. 用户查看视频 01 和视频 02 v2 的素材表现；
5. 勾选两条素材进行对比；
6. 页面显示视频 01 的点击率和转化率更高；
7. Agent 同时提示两条素材存在多个不同变量，不能直接归因；
8. 用户点击“保存为复盘观察”；
9. 将结论可信度设为“初步观察”；
10. 保存到创意知识库；
11. 用户点击“创建对照改版”；
12. 返回 Agent 工作台；
13. Agent 携带当前数据并创建下一轮对照素材需求。
