# 第 6 页：素材库

## 1. 页面目标

运营在素材库完成：

1. 查找已经审核通过的图片和视频；
2. 查看素材对应的商品、活动、方案和审核记录；
3. 下载或批量整理素材；
4. 选择素材进入投放；
5. 基于已有素材创建新的改版任务；
6. 查看素材投放状态并归档失效素材。

素材库只存放已经生产完成的营销素材，不与商品原图、Logo、字体等品牌资产混在一起。

## 2. 整体布局

采用两栏结构：

- 左侧全局导航栏：240px；
- 右侧素材库主区域：自适应宽度；
- 点击素材后，从右侧打开 480px 素材详情抽屉。

## 3. 左侧导航栏

展示：

- 工作空间；
- 新建素材任务；
- Agent 工作台；
- 任务中心；
- 审核与返工；
- 素材库；
- 投放中心；
- 数据分析；
- 最近对话；
- 用户信息。

“素材库”使用紫色选中状态。

## 4. 页面顶部

### 4.1 标题区域

展示：

- 标题：“素材库”；
- 说明：“查找、复用和投放已经审核通过的营销素材”；
- 右侧按钮：“新建素材任务”。

点击“新建素材任务”返回 Agent 工作台。

### 4.2 素材统计

横向展示：

- 全部素材：128；
- 可投放：86；
- 投放中：24；
- 即将失效：6；
- 本周新入库：18。

点击统计项自动应用对应筛选条件。

## 5. 素材状态页签

展示：

- 全部；
- 可投放；
- 投放中；
- 已下线；
- 可复用；
- 已归档。

“可投放”表示：

- 已经审核通过；
- 商品有效；
- 承接页面有效；
- 活动信息未过期；
- 当前版本可以进入投放。

## 6. 搜索与筛选

### 6.1 搜索框

占位提示：

> 搜索素材名称、商品、活动或创意方向

支持输入：

> 夏季女装拉新视频

### 6.2 筛选条件

提供：

- 素材类型：图片、视频；
- 商品；
- 活动；
- 创意方向；
- 素材规格；
- 投放渠道；
- 创建时间；
- 审核人；
- 投放状态。

### 6.3 快捷筛选

展示：

- 我创建的；
- 本周新增；
- 尚未投放；
- 有历史投放数据；
- 即将过期。

### 6.4 排序

支持：

- 最近入库；
- 最近使用；
- 投放次数；
- 点击率；
- 转化率。

点击率和转化率只展示已有数据，不对无投放记录的素材虚构结果。

## 7. 素材展示区域

默认使用卡片网格，每行 4 张。

用户可以切换：

- 卡片视图；
- 列表视图。

### 7.1 素材卡片

每张卡片展示：

- 图片或视频缩略图；
- 视频时长或图片尺寸；
- 素材名称；
- 素材版本；
- 对应商品；
- 创意方向；
- 当前状态；
- 入库时间；
- 投放次数；
- 多选复选框；
- 更多操作。

### 7.2 视频卡片示例

> 视频 01｜冰丝通勤衬衫场景种草  
> v1｜9:16｜15 秒  
> 可投放｜今天 11:10 入库

### 7.3 返工版本示例

> 视频 02｜法式收腰连衣裙场景种草  
> v2｜9:16｜15 秒  
> 复审通过｜今天 11:24 入库

卡片上显示：

> v2 返工版本

不显示已驳回的 v1 为当前可用版本。

### 7.4 卡片快捷操作

鼠标移入后显示：

- 预览；
- 下载；
- 去投放；
- 基于此素材新建；
- 更多。

## 8. 新入库提示

用户从审核页进入素材库时，页面顶部显示：

> 视频 01 和视频 02 v2 已通过审核并进入素材库。

对应素材卡片：

- 排在列表前方；
- 显示“新入库”标签；
- 使用短暂高亮效果；
- 页面自动滚动到对应位置。

## 9. 素材详情抽屉

点击素材卡片后打开。

### 9.1 抽屉顶部

展示：

- 素材名称；
- 当前版本；
- 当前状态；
- 收藏按钮；
- 更多操作；
- 关闭按钮。

### 9.2 素材预览

视频素材支持：

- 播放和暂停；
- 进度拖动；
- 静音；
- 字幕开关；
- 全屏。

图片素材支持：

- 放大；
- 缩小；
- 查看原始尺寸；
- 适应画布。

### 9.3 基础信息

展示：

- 素材类型；
- 尺寸或比例；
- 视频时长；
- 文件大小；
- 创意方向；
- 入库时间；
- 创建人；
- 审核人；
- 当前版本。

## 10. 业务关联信息

展示：

- 对应商品；
- 商品当前价格；
- 商品库存状态；
- 对应活动；
- 承接页面；
- 目标人群；
- 投放渠道；
- 原始需求；
- 原始方案；
- 生产任务。

可点击：

- 查看商品；
- 预览承接页；
- 查看原始方案；
- 查看生产任务；
- 返回 Agent 讨论。

## 11. 可投放检查

素材详情中展示实时检查结果：

- 审核状态：已通过；
- 商品状态：有效；
- 商品库存：充足；
- 活动状态：进行中；
- 承接页面：有效；
- 素材规格：符合短视频信息流要求。

全部通过时显示：

> 当前素材可以用于投放。

主按钮：

> 去投放

## 12. 素材失效与风险

即使素材曾经审核通过，也可能因为业务信息变化而不再适合投放。

### 12.1 活动即将过期

显示：

> 素材中的活动信息将在 2 天后失效。

用户可以：

- 立即投放；
- 基于此素材制作新版；
- 标记为活动结束后归档。

### 12.2 商品库存不足

显示：

> 关联商品库存偏低，建议确认补货情况后再投放。

### 12.3 承接页失效

显示：

> 原承接页面已经下线，当前素材暂不可投放。

“去投放”按钮不可用。

提供：

- 更换承接页并制作新版；
- 返回 Agent 处理。

### 12.4 文案信息过期

如果素材中包含过期价格或活动时间，状态变为：

> 不可投放，需要改版

不能直接修改已审核通过的素材，必须创建新版本。

## 13. 素材版本

点击“版本记录”展示：

### v1

- 创建时间；
- 审核结果：已驳回；
- 驳回原因；
- 问题位置：镜头 4 Logo 组件；
- 状态：历史版本，不可投放。

### v2

- 创建时间；
- 修改内容；
- 复审结果：通过；
- 状态：当前版本，可投放。

用户可以对比 v1 和 v2，但不能恢复已驳回版本用于投放。

## 14. 完整追溯

点击“查看完整追溯”打开时间线：

- 原始运营需求；
- Agent 需求确认；
- 商品和承接页确认；
- 创意方案 v1；
- 分镜 v1；
- 生产任务；
- 自动质检；
- 审核驳回；
- 分镜或组件 v2；
- 复审通过；
- 素材入库；
- 后续投放记录。

运营默认看到业务过程。

Prompt 版本、模型版本和合成参数放在“高级生产记录”折叠区域，只读展示，不作为日常操作内容。

## 15. 下载素材

点击“下载”后弹出选项：

- 下载当前视频或图片；
- 同时下载封面图；
- 同时下载字幕文件；
- 同时下载素材信息表。

按钮：

- 取消；
- 确认下载。

Demo 中模拟下载成功并提示：

> 素材已准备完成。

## 16. 基于此素材新建

点击“基于此素材新建”后，不直接修改当前素材。

页面弹出：

> 你希望如何调整这份素材？

快捷选项：

- 修改活动价格；
- 更换商品；
- 更换承接页；
- 调整视频比例；
- 修改文案；
- 生成相似创意；
- 自定义修改。

选择后：

1. 返回 Agent 工作台；
2. 自动携带当前素材、商品和方案信息；
3. Agent 询问具体修改内容；
4. 创建新的需求和方案版本；
5. 原素材保持不变。

## 17. 去投放

点击“去投放”后：

1. 系统再次检查审核、商品、活动和承接页状态；
2. 检查通过后进入投放中心；
3. 自动带入当前素材；
4. 用户继续配置投放渠道、时间和投放名称。

如果检查失败，留在当前页面并说明具体原因。

## 18. 批量操作

勾选多个素材后，页面底部出现批量操作栏：

- 批量下载；
- 批量加入投放；
- 添加到素材集合；
- 批量归档。

### 18.1 批量加入投放

只有全部满足以下条件时才允许：

- 审核通过；
- 当前版本有效；
- 商品有效；
- 承接页有效；
- 素材规格兼容。

不满足条件的素材需要单独说明原因。

### 18.2 素材集合

用户可以创建集合，例如：

- 夏季女装拉新素材；
- 七夕活动素材；
- 高点击率通勤素材；
- 待二次改版素材。

集合只用于整理，不改变素材状态。

## 19. 归档素材

点击“归档”后弹出确认框：

> 归档后素材不会删除，但默认不再出现在可投放素材中。

归档原因：

- 活动结束；
- 商品下架；
- 素材过期；
- 已有新版替代；
- 其他。

正在投放的素材不能直接归档，必须先停止投放。

## 20. 页面状态

### 20.1 空状态

展示：

> 素材库中还没有内容。素材通过审核后会自动进入这里。

按钮：

- 查看审核队列；
- 新建素材任务。

### 20.2 可投放

素材审核和业务有效性检查均通过。

### 20.3 投放中

显示当前投放数量和投放渠道。

### 20.4 已下线

素材曾经投放，但当前没有运行中的投放。

### 20.5 即将失效

活动、价格或承接页面即将到期。

### 20.6 不可投放

显示具体原因，不只显示红色状态。

### 20.7 已归档

素材只读，可查看历史记录和重新创建新版。

### 20.8 加载失败

展示：

> 暂时无法加载素材，请重新加载。

## 21. Demo 主演示路径

1. 用户从审核页点击“查看已入库素材”；
2. 素材库自动定位视频 01 和视频 02 v2；
3. 用户打开视频 02 v2 详情；
4. 查看商品、承接页、审核记录和版本记录；
5. 查看 v1 被驳回、v2 复审通过的完整关系；
6. 关闭详情抽屉；
7. 勾选视频 01 和视频 02 v2；
8. 点击“批量加入投放”；
9. 系统检查两条素材均可投放；
10. 进入投放中心并自动带入两条素材。

## 22. 页面跳转关系

| 用户操作 | 跳转结果 |
| --- | --- |
| 点击“新建素材任务” | 返回 Agent 工作台并打开新对话 |
| 点击素材卡片 | 打开素材详情抽屉 |
| 点击“查看原始方案” | 进入方案确认页只读状态 |
| 点击“查看生产任务” | 进入任务中心并定位对应任务 |
| 点击“返回 Agent 讨论” | 返回对应 Agent 对话 |
| 点击“查看审核记录” | 进入审核与返工页历史记录 |
| 点击“基于此素材新建” | 返回 Agent 工作台并携带素材信息 |
| 点击“去投放” | 进入投放中心并带入当前素材 |
| 点击“批量加入投放” | 进入投放中心并带入选中素材 |
| 点击“查看投放数据” | 进入数据分析页并筛选当前素材 |
