# 第 2 页：Agent 工作台

## 1. 页面目标

这是用户登录后的首页，也是整个产品的总入口。用户可以在这里：

1. 向 Agent 提出新的素材需求；
2. 继续历史对话和未完成任务；
3. 查看需要自己处理的关键待办；
4. 前往方案确认、任务中心、审核与返工、素材库、投放中心和数据分析页面；
5. 随时返回工作台，继续让 Agent 协助处理问题。

## 2. 整体布局

采用类似 Codex 的三栏结构，基准尺寸为 1440×900：

- 左侧导航栏：240px；
- 中部 Agent 对话区：自适应宽度；
- 右侧任务上下文栏：320px，可折叠；
- 页面不出现模型、Prompt、模型路由等内部技术信息。

## 3. 左侧导航栏

### 3.1 顶部工作空间

展示：

- 品牌 Logo；
- “星河女装增长团队”；
- 当前用户角色“运营负责人”；
- 下拉切换工作空间；
- 点击后可返回登录页的工作空间选择状态。

### 3.2 新建任务

顶部放置高强调按钮：

> ＋ 新建素材任务

点击后：

- 中部打开新的空白对话；
- 右侧任务上下文清空；
- 输入框自动获得焦点。

### 3.3 页面导航

依次展示：

- Agent 工作台；
- 任务中心；
- 审核与返工；
- 素材库；
- 投放中心；
- 数据分析。

当前页面“Agent 工作台”使用紫色选中状态。

导航右侧显示待办数字：

- 任务中心：1；
- 审核与返工：3；
- 投放中心：2。

### 3.4 最近对话

展示最近 5 条对话：

- 夏季女装 10 条拉新视频；
- 七夕活动主图制作；
- 新客优惠券素材修改；
- 通勤女装商品推广；
- 夏装活动投放复盘。

每条对话显示：

- 对话标题；
- 当前阶段；
- 最后更新时间；
- 异常或待确认标识。

点击后恢复对应对话和右侧任务上下文。

### 3.5 底部区域

展示：

- 帮助中心；
- 消息通知；
- 用户头像和姓名；
- 账号设置；
- 退出登录。

## 4. 中部默认首页

用户刚进入工作台、尚未打开对话时展示。

### 4.1 欢迎信息

标题：

> 上午好，林晓。今天想制作什么营销素材？

副标题：

> 直接告诉我业务目标，我会帮你补全需求、推荐商品并推进素材生产。

### 4.2 核心输入框

大尺寸输入框，占页面中部主要视觉位置。

占位提示：

> 例如：从夏季女装中选择合适商品，生成 10 条竖屏拉新视频

输入框底部提供：

- 添加附件；
- 选择已有商品；
- 选择活动；
- 发送按钮。

输入框上方不要求用户填写复杂表单。

### 4.3 快捷需求

输入框下方展示四个快捷入口：

- 生成促销视频；
- 制作商品主图；
- 批量改版已有素材；
- 根据投放数据优化素材。

点击后将示例需求写入输入框，用户仍可修改。

### 4.4 我的待办

展示四张可点击卡片：

- 2 个方案待确认；
- 1 个生产异常待处理；
- 3 个素材待审核；
- 2 个素材待投放。

点击分别跳转：

- 方案待确认 → 方案确认页；
- 生产异常 → 任务中心；
- 素材待审核 → 审核与返工页；
- 素材待投放 → 投放中心。

### 4.5 最近任务

列表展示：

- 任务名称；
- 素材类型；
- 当前阶段；
- 完成进度；
- 最后更新时间；
- “继续处理”按钮。

示例：

> 夏季女装 10 条拉新视频｜视频｜方案待确认｜今天 10:24｜继续处理

点击“继续处理”后打开对应对话，并恢复右侧任务上下文。

## 5. 中部对话状态

用户发送需求后，中部首页切换为对话界面。

### 5.1 对话顶部

展示：

- 对话标题“夏季女装 10 条拉新视频”；
- 当前状态“需求补充中”；
- 更多操作；
- 重命名；
- 归档对话。

### 5.2 对话内容

用户消息靠右，Agent 消息靠左。

Agent 回复组合使用：

- 简短说明；
- 单选或多选选项；
- 商品卡片；
- 需求摘要卡片；
- 风险提示；
- 页面跳转按钮。

### 5.3 首轮对话示例

用户输入：

> 从夏季女装中选择合适商品，生成 10 条竖屏促销视频，用于拉新。

Agent 回复：

> 收到。你希望生成 10 条夏季女装拉新视频。开始选品前，我需要确认“10 条”的具体含义。

选项：

- 10 个商品，每个商品 1 条；
- 5 个商品，每个商品 2 条；
- 从少量商品生成 10 个不同创意版本；
- 我自己指定。

用户选择后，Agent 继续询问：

- 投放渠道；
- 目标人群；
- 视频时长；
- 用户点击后的承接页面。

每次只追问当前必要的信息，不一次展示大量表单。

### 5.4 需求摘要卡片

信息补充完成后，Agent 展示结构化摘要：

- 业务目标：拉新；
- 素材类型：竖屏视频；
- 生产数量：10 条；
- 投放渠道：短视频信息流；
- 目标人群：25—35 岁通勤女装新客；
- 视频规格：9:16、15 秒；
- 选品范围：夏季女装；
- 承接页面：清凉一夏活动页。

卡片底部提供：

- 修改需求；
- 确认并进入方案。

点击“确认并进入方案”后跳转方案确认页。

### 5.5 输入区

固定在中部底部，包含：

- 多行文字输入；
- 上传附件；
- 选择商品；
- @已有任务；
- 发送按钮。

当用户必须先完成页面确认时，输入框上方提示：

> 方案正在等待你的确认，你也可以继续向 Agent 提问。

## 6. 右侧任务上下文栏

右侧栏只展示运营需要判断的信息。

### 6.1 当前任务

展示：

- 任务名称；
- 素材类型；
- 当前阶段；
- 创建时间；
- 负责人。

### 6.2 当前进度

展示业务阶段：

1. 需求确认；
2. 选品与承接；
3. 创意与分镜；
4. 素材生产；
5. 审核入库；
6. 投放复盘。

状态区分：

- 已完成；
- 当前处理中；
- 等待用户确认；
- 尚未开始；
- 存在异常。

点击已经开放的阶段，跳转到对应页面或恢复相关对话。

### 6.3 待用户确认

只在有待办时展示，例如：

> 商品和承接页等待确认

按钮：

> 继续确认方案

点击进入方案确认页的对应位置。

### 6.4 关联对象

展示：

- 已选商品：6 个；
- 承接页面：清凉一夏活动页；
- 素材数量：10 条；
- 当前版本：方案 v1。

点击商品或承接页，可打开简要抽屉查看，不离开工作台。

### 6.5 快速前往

固定展示：

- 查看方案；
- 查看生产任务；
- 查看审核结果；
- 查看已入库素材；
- 查看投放数据。

未到达的阶段显示灰色不可用状态，并说明：

> 素材通过审核后可查看。

## 7. Agent 工作台的跳转关系

| 用户操作 | 跳转结果 |
| --- | --- |
| 点击“新建素材任务” | 打开空白 Agent 对话 |
| 点击最近对话 | 恢复对应对话和任务上下文 |
| 点击“方案待确认” | 进入方案确认页 |
| 点击“生产异常” | 进入任务中心并定位异常任务 |
| 点击“素材待审核” | 进入审核与返工页 |
| 点击“素材待投放” | 进入投放中心 |
| 点击需求摘要中的“确认并进入方案” | 进入方案确认页 |
| 点击右侧“查看生产任务” | 进入任务中心 |
| 点击右侧“查看审核结果” | 进入审核与返工页 |
| 点击右侧“查看已入库素材” | 进入素材库 |
| 点击右侧“查看投放数据” | 进入数据分析页 |
| 其他页面点击侧边栏“Agent 工作台” | 返回当前任务对应的 Agent 对话 |

## 8. 页面状态

### 8.1 默认状态

展示欢迎语、需求输入框、待办和最近任务。

### 8.2 Agent 理解中

发送按钮变为停止按钮，对话中显示：

> Agent 正在理解需求并检查缺失信息……

### 8.3 等待用户补充

显示问题和可选答案，右侧阶段为“需求确认”。

### 8.4 等待方案确认

对话中展示需求摘要，右侧出现“继续确认方案”。

### 8.5 任务生产中

对话顶部显示生产进度，右侧可前往任务中心。

### 8.6 存在异常

最近对话、左侧任务中心和右侧进度同时出现橙色提醒。

Agent 消息说明：

> 其中 1 条视频的第 4 镜生成失败，其他内容不受影响。系统正在局部重试。

### 8.7 无历史任务

不展示最近任务列表，改为空状态：

> 还没有任务，从一句需求开始创建第一批素材。

### 8.8 无权限

用户点击无权限页面时不离开工作台，提示：

> 你没有投放权限，可联系工作空间管理员申请。

## 9. Demo 主演示路径

1. 用户从登录页进入 Agent 工作台；
2. 首页显示待办、最近任务和新需求输入框；
3. 用户输入“从夏季女装中选择合适商品，生成 10 条竖屏促销视频，用于拉新”；
4. Agent 识别“10 条”存在歧义并追问；
5. 用户选择“从少量商品生成 10 个不同创意版本”；
6. Agent 依次询问渠道、人群、时长和承接页；
7. 用户完成回答；
8. Agent 生成需求摘要；
9. 用户点击“确认并进入方案”；
10. 跳转到方案确认页。
